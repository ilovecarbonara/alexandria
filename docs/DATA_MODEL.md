# Data Model

## Supabase Tables

### users
| column          | type      | notes                          |
|-----------------|-----------|--------------------------------|
| id              | uuid (PK) | Supabase auth user id          |
| email           | text      | Must be @uspf.edu.ph           |
| full_name       | text      |                                |
| is_approved     | boolean   | Admin approves before access   |
| is_admin        | boolean   | Only one seeded admin          |
| is_active       | boolean   | Admin can deactivate users     |
| last_active_at  | timestamptz | Updated on authenticated requests |
| created_at      | timestamp |                                |

### theses
| column           | type      | notes                                      |
|------------------|-----------|--------------------------------------------|
| id               | uuid (PK) |                                            |
| user_id          | uuid (FK) | references users.id                        |
| title            | text      |                                            |
| title_normalized | text      | lowercased, stripped — used for similarity matching |
| author_name      | text      |                                            |
| thesis_level     | enum      | undergraduate, masteral, doctoral          |
| thesis_category  | text      | user-selected from predefined list         |
| submission_type  | enum      | draft, final                               |
| sha256_hash      | text      | unique per entry                           |
| tx_hash          | text      | blockchain transaction hash                |
| block_timestamp  | timestamp | timestamp from blockchain                  |
| previous_thesis_id | uuid (FK) | nullable, references theses.id — links version chain |
| registered_at    | timestamp | system registration time                   |
| status           | enum      | pending, accepted, flagged, rejected       |

### disputes
| column          | type      | notes                                      |
|-----------------|-----------|--------------------------------------------|
| id              | uuid (PK) |                                            |
| thesis_id       | uuid (FK) | references theses.id                       |
| flagged_by      | uuid (FK) | references users.id                        |
| reason          | text      | user-written or auto-generated by similarity system |
| status          | enum      | open, resolved                             |
| created_at      | timestamp |                                            |

### title_alerts
| column             | type      | notes                                                  |
|--------------------|-----------|--------------------------------------------------------|
| id                 | uuid (PK) |                                                        |
| new_thesis_id      | uuid (FK) | references theses.id — the incoming registration       |
| matched_thesis_id  | uuid (FK) | references theses.id — the existing entry that matched |
| notified_user_id   | uuid (FK) | references users.id — who received the alert           |
| similarity_score   | float     | 0.0–1.0 score from pg_trgm at time of match            |
| status             | enum      | notified                                               |
| created_at         | timestamp |                                                        |

### activity_logs
| column          | type      | notes                                      |
|-----------------|-----------|--------------------------------------------||
| id              | uuid (PK) |                                            |
| user_id         | uuid (FK) | references users.id                        |
| action          | text      | description of the action                  |
| created_at      | timestamp |                                            |

## Smart Contract (Solidity)

### Struct: ThesisRecord
- sha256Hash: string
- submissionType: string
- thesisLevel: string
- thesisCategory: string
- timestamp: uint256
- registeredBy: address

### Functions
- registerThesis(hash, submissionType, level, category) → emits ThesisRegistered event
- getThesis(hash) → returns ThesisRecord
- isRegistered(hash) → returns bool

### Events
- ThesisRegistered(hash, registeredBy, timestamp)
